# 📊 Analyzing Companies’ Financial Health with Nasdaq Data

## Overview
This project analyzes company financial performance  Nasdaq Data Link MER/F1 dataset, which includes balance sheets, income statements, and cash flow metrics.
The focus is on Accrued Expenses Turnover (AET), a key efficiency ratio, analyzing over time frame (2010–2015) and across countries.

## Installation:

**Clone the repo and install dependencies:**
- git clone https://github.com/<your-username>/nasdaq-financial-analysis.git
- cd nasdaq-financial-analysis
- pip install -r requirements.txt
- python analysis.py
